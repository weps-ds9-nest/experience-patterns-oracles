# 26 Steps of Product Dashboard Design: Complete Process Guide

Four-year journey as product designer learning dashboard design producing complete 26-step process: Pre-Process (get information via three examples, learn personas creating 4-5 personas with actual users, setup exact trackable goals, set up project folder with moodboard), Going Low Fidelity (whiteboard sketching with everyone, map all screens and user inputs, write down all possible states including empty states, prepare first interaction diagram via tools like Camunda Modeler), Work/Design (create moodboard discussing visual ideas, first draft getting feedback mixing screens, write copy and tone as crucial design aspect, conduct first intern test with 3-4 non-involved people, maintain etiquette keeping Sketch files tidy with max 8 layers per folder, put everything on canvas before designing details, create UI elements and play with Lego/components with resizing properties), Assets & Delivery (write specifications in Google Docs, create diagram for team printing/discussion, prepare final prototype in Marvelapp/Invision, record QuickTime video going through prototype, animate interactions using After Effects/Principle, create styleguide showing different scenarios), Final & Test (setup Inspectlet/HotJar for user session recording, use Mixpanel validating goals, track clicks with Google Analytics, integrate Intercom).

## Key Patterns & Concepts

- **Pre-Process Discovery**: Collect three inspirational examples enabling clarity for both parties; talk with dev team extensively
- **Personas**: Create 4-5 personas with actual users; understand design solutions' edge cases
- **Exact Goals**: Establish clear trackable goals before designing; understand what to measure
- **Project Structure**: Organize folders: Source Files, Screens & Export, Inspiration & Resources; collect moodboards
- **Whiteboard Sketching**: Everyone sketches ideas together enabling diverse perspectives; address edge cases early
- **Screen Mapping**: List user inputs and stories; ensure clear understanding before design
- **State Documentation**: Address all possible states including empty states; prepare users for non-ideal conditions
- **Interaction Diagram**: Use tools like Camunda Modeler for scalable diagrams with automatic line/arrow generation
- **Moodboards**: Create mood boards discussing visual ideas before pixel-level work
- **First Draft Feedback**: Mix screens creating realistic early drafts; gather team feedback without perfection
- **Copy and Tone**: Write copy as crucial design aspect; set appropriate tone for communication
- **First User Test**: Prototype with 3-4 non-involved people; test flows and scenarios; validate questioning skills
- **File Organization**: Maximum 8 layers per folder; create new folders when exceeding limit
- **Canvas Content**: Put all content on canvas first before designing details; easier to design with content in place
- **Component Systems**: Use Sketch shapes with resizing properties enabling drag-and-drop component system
- **Specifications**: Write detailed specifications in Google Docs or Sketch; communicate design decisions; enable team reference
- **Diagrams**: Create printable diagrams for team discussion showing full design flow
- **Final Prototype**: Prepare 3-5 prototypes for presentation; have all states ready; use Marvelapp/Invision
- **Video Documentation**: Record QuickTime video walking through prototype and explaining design; useful for remote teams
- **Animation**: Use After Effects or Principle for final interaction animations explaining movement and hover states
- **Styleguide**: Create comprehensive styleguide showing different component scenarios, error states, disabled states
- **User Tracking**: Use Inspectlet/HotJar recording user sessions; track particular features via page filtering
- **Goal Validation**: Use Mixpanel validating initial goals; measure flow completion rates and drop-off points
- **Click Tracking**: Setup Google Analytics click tracking on all buttons and links; discover behavioral patterns
- **Integration**: Integrate tools like Intercom for enhanced support and feedback
