18 February 2024

My friend Victor shared this design tip on Twitter last week:

![Image 1](https://adamsilver.io/assets/images/sliders-degrade-ux-so-do-this-instead/victor.jpeg)

He said that if you put the slider values on top, your finger won’t cover them up.

It’s a useful tip.

But sliders aren’t just bad UX because your finger covers up the values. This is the least of your worries.

Here I’ll share why that is (plus what to do instead):

## Reason 1: They’re hard to control

This is because it takes a lot of effort to move the slider into the position. This is even harder if you:

*   need to be precise
*   have motor impairments
*   have ridiculously long purple nails (like my friend Rach)

![Image 2](https://adamsilver.io/assets/images/sliders-degrade-ux-so-do-this-instead/nails.jpeg)

## Reason 2: The values cannot be clearly labelled

This is because there’s limited space to fit labels in.

So you end up with gaps or line markers which are ambiguous and make users work harder.

## Reason 3: They’re hard to fit on small screens

Sliders need to be big enough to interact with properly.

Squeezing the slider into a small space makes it even harder to use.

## Reason 4: They have an upper limit

Sliders have an upper limit which is fine when it’s a percentage value.

But it doesn’t work well for values like price.

## Do this instead

If the user needs to be precise, use two inputs:

![Image 3](https://adamsilver.io/assets/images/sliders-degrade-ux-so-do-this-instead/inputs.png)

Left: Slide with 2 handles for min and max price. Right: 2 separate inputs for min and max price.

If the user does not need to be precise, use checkboxes:

![Image 4](https://adamsilver.io/assets/images/sliders-degrade-ux-so-do-this-instead/checkboxes.png)

Left: Slide with 2 handles for min and max price. Right: 4 checkboxes with different price ranges.

Both patterns are easy to use and work on mobile.

But there’s an even more important lesson here.

Because Victor was thoughtful, no doubt. He looked at the slider, spotted an issue and came up with better UX.

But improving a bad pattern doesn’t make it good. You’re usually better off finding another pattern altogether.
