# Designing Better Dashboards

Designing dashboards feels overwhelming when facing multiple data requirements across different business channels. Two core principles help: design for scale recognizing data volume grows continuously, and leverage widgets providing extra context reducing cognitive load and decision-making time. Widgets add context-rich information about viewed data helping users make better decisions. Modals extend details of specific components adding context before user actions, often eliminating need for separate pages. Dashboards most effective when information clearly conveys meaning; designers must understand context behind displayed data informing design decisions.

## Key Patterns & Concepts

- **Design for Scale**: Treat dashboard as organic matter; data volume continuously grows; anticipate future dataset expansion
- **Future-Proof Design**: Analyze business understanding which datasets likely increase in volume and functions; design accordingly
- **Widgets as Context**: Add extra layers of context to displayed information; reduce overall click times and decision-making time
- **Widget Benefits**: Reduce cognitive load; accelerate decision-making; provide supporting context for user actions
- **Modals for Extended Details**: Extend component details via modals rather than separate pages; add context before user action
- **Modal Advantages**: Modal extension handles more than regular dialog; often eliminates separate pages
- **Information Clarity**: Dashboard only effective as information conveyed; understand context behind displayed data
- **Design Decisions**: Context understanding greatly informs design choices and approach
- **Practical Examples**: Filter and notification systems for troubled data (contracts); extended modals with additional widget context
