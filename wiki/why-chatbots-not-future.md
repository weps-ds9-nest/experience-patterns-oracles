# Why Chatbots Are Not the Future of Interfaces

Chatbots limited for AI interface evolution due to four fundamental problems: text inputs lack affordances—users don't know system capabilities without trial/error; prompts just pile of context—everything typed context requiring users figuring what prompts work; responses isolated—users can't navigate to right granularity after AI responds; implementation-evaluation loop forces constant mode switching between doing work and reading responses losing flow state. Chat interface forces users between tweaking prompt and reading response, frequently switching modes preventing sustained focus. Good tools communicate clearly how used and how not used; gloves shape-communicate function immediately; chat looks identical to search box, login form, credit card field. No visual signal what system expects or can do. When tasks partially automated, "no man's land" emerges where humans still deciding but not in control. Better approach: offer suggestions helping clarity not replacing thinking, manipulate geometry in latent space like sculpting prose, chain models supporting object movement in video not just pixel manipulation. Build tools not machines to operate. Embrace humanity using AI deftly, not generating more content for evaluation.

## Key Patterns & Concepts

- **Missing Affordances**: No visual cues what system does; no scaffolding for iterative refinement; no persistent context representation
- **Context Piles**: Everything in prompt is context piece; users must figure what prompts work; burden on every user learning
- **Isolated Responses**: Can't navigate to right granularity after response; tedious scrolling line-by-line comparing; no working buffer
- **Implementation-Evaluation Loop**: Two distinct actions (implementing, evaluating) present all crafts; AI forces frequent switching losing flow state
- **No Man's Land Automation**: When tasks <100% human but >0% machine, humans deciding but not controlling outcome; feels like machine operation
- **Craft vs Operation**: Operating machine (pressing buttons) lacks craft; tools preserve human control; design crucial for partial automation
- **Visual Learning**: Glove function immediately obvious; chat box looks like generic input field; no distinction from search, login, payment
- **Interface Could Be Baked**: All prompt context could be controls, fields, sliders; users could specify: writing type, audience, feel, inspirations
- **Better Approach**: Suggest gaining clarity, manipulate geometry like sculpting, chain models under hood for object movement
- **Humanity Embrace**: Use AI deftly not blindly improve efficiency; real game-changers involve crafted interface not plain content generation
- **Spectrum Principle**: Spectrum from human task (0% machine) through tool (50% machine) to machine (100% machine); interface crucial at 50% point
- **Design Maturity**: Adding controls, information, affordances to chat makes more usable; field becoming mature building tools not machines
