# We Need UX Patterns for AI Behaviour, Not Just UI Components

UX design increasingly about what AI does next not just what users see. AI systems suggesting, predicting, adapting, occasionally hallucinating require behavioral UX patterns guaranteeing predictability and trust. Traditional UX thrives consistency; same input produces same output. AI breaks model: same question yields different answers, same AI says "don't know" today then answers tomorrow. Five behavioral patterns essential: "Explain yourself" (sources/reasoning transparency), "Let me fix it" (graceful revision without restarting), "Remember who I am" (context persistence across sessions), "Ask before assuming" (boundary definition avoiding premature suggestions), "Fail like a pro" (graceful limitation acknowledgment). These patterns aren't just features but building blocks of responsibility map showing where judgment lies when systems break.

## Key Patterns & Concepts

- **Behavioral UX Patterns**: Design AI behavior predictability, trustworthiness, human-awareness; not just visual UI
- **Traditional vs AI UX**: Consistency (same input→same output) vs probability (same question→different answers)
- **Transparency Pattern**: Display sources, references, steps behind output; use footnotes, tooltips, expandable logic; verify not just trust
- **Revision Pattern**: Let users revise AI output without starting over; offer meaningful task-specific refinements; expose sufficient control
- **Memory Pattern**: Preserve useful context across sessions; surface what AI remembers; allow editing/reset; make memory visible and manageable
- **Initiative Pattern**: Define how and when AI should initiate; use trigger thresholds; ask permission; match initiative to context
- **Failure Pattern**: Gracefully acknowledge limitations; offer paths to retry, refine, escalate; normalize failure in interaction flow
- **Real-World Examples**: ChatGPT Regenerate button, Notion AI tone/length controls, GitHub Copilot transparency, Google AI Overviews sources
- **Responsibility Mapping**: Interface determines where judgment/accountability lies when systems fail
- **Emerging Standards**: Most design systems stop at components; few offer AI behavior patterns; no shared standard yet but will develop
- **Designer Maturity**: Designers figuring out behavioral patterns leading shift; those learning design behavior not just looks lead adoption
- **Future Direction**: Consistency in visuals nailed; now need consistency in intelligence; behavior patterns becoming new design system
