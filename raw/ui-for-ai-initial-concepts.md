For the last two weeks, the UI for AI team has been working on generating concepts that solve the various issues with current AI systems. The following is a collection of ideas and explorations.

As you’ll see, these are sketches, designed to convey an idea in a rough but understandable way. Every concept has a user problem it was focused on improving. Some of these concepts—indeed, many of them—overlap. Our next step is to combine them into holistic patterns that we can refine and prototype.

Reviewing the concept sketches

## The Concepts

The team generated over 40 concepts. We voted on the concepts we wanted to explore further—you’ll see our green voting dots in the images. Here are the 24 concepts in alphabetical order:

### AI Prompt Generation

How can users better edit their prompts for the desired output? **AI Prompt Generation** provides flexible options for users to iterate on AI-suggested prompts, while still having the ability to manually edit.

### Bookmark Tab

Currently, users have to scroll a lot to find previous outputs they want to see or reuse. The linear structure also restricts using multiple prompts at once. A **Bookmark Tab** would collect prompts to reuse or review.

### BranchFlow

Linear chats make it hard to explore multiple ideas and keep context. **BranchFlow** lets users branch AI responses into visual trees, auto-cluster related ideas, and transition seamlessly into structured workflows.

### Chat Navigator

Users struggle to navigate and reference specific points within long AI conversations, making it difficult to find and revisit past ideas. **Chat Navigator** lets users star key moments and view them at a glance, enabling quick previews on hover and quick navigation back to relevant parts of the conversation.

### Contexts

Users struggle to mentally track and resume multiple ongoing AI conversations or tasks spread across different chats. **Contexts** gives users AI-generated workflow threads that can span across chats. The widget allows users to quickly switch between recently accessed contexts and users can jump to the most recent instance of the context.

### Conversational Memory

An Al chat interface that makes memory transparent and controllable within the natural flow of conversation by showing in-line citations when Al uses memories, real-time confirmations when creating new memories, and allowing users to anchor exact phrases.

### Dual-mode AI Workspace

Different users need different workflows—creatives want flexibility, while others need structure and consistency. The **Dual-mode AI Workspace** offers a freeform canvas for exploration and a guided workspace for structured goal-oriented tasks in one interface.

### Fine-tune Pop-ups

Users sometimes only want to modify part of a prompt. **Fine-tune Pop-ups** allow for specific fine-tuning to improve, explain, or modify the tone of a selected area.

### Highlight Attached Files

It’s sometimes hard to tell what is important in the attached documents. Users can highlight priorities in a document for the AI.

### Highlight What’s Important

Users sometimes need the ability to tell the AI what the priorities are in a prompt. Users can highlight the prompts themselves, or the AI can provide suggested highlights first. The user can also play with typographic hierarchy by bolding, italicizing, and changing font sizes.

### Info Clusters

Too many conversations without an easy way to get an overview or export them to other AI services.

### Memory Citations

There can be a lack of context as to where a memory is coming from. **Memory Citations** would show where memories are being pulled from.

### Memory Context

Users can have many long conversations that they might want to go back to. **Memory Context** provides more robust groups and an organizational structure to memories.

### Memory Setup

LLMs often don’t remember things between sessions. Users can do (as an optional task) a quick **Memory Setup** to remind the AI what their settings and priorities are.

### Multi-level Refinement

Users need to refine AI outputs at different levels (e.g. whole drafts, sentences, words). Current tools make this clunky, often forcing full regenerations or overwhelming menus. Multi-level Refinement provides two clear entry points: option-level icons for big-picture edits (rewrite, merge, tone) and inline highlighting for precise changes (refine, rewrite, suggest alternatives).

### Preview of Source

Users have to do their own fact-checking by clicking on source websites and hunting for information. Showing a preview of the source lets users fact-check without leaving the AI.

### Prompt Suggestions

The blank canvas can be a hurdle for users who might be unsure how to create a good prompt. **Prompt Suggestions** offers ways to improve a prompt before it is submitted.

### Prompt Modes

Users often face a blank chat box without a clear sense of what the AI can actually do, making it hard to start or frame their request effectively. By introducing **Prompt Modes** (e.g. Research, Design, etc.) along with the chat box, the design guides users with a clearer sense of the AI’s capabilities while keeping the experience flexible.

### Prompting Guide

When the user inputs a large chunk of text with multiple goals/contexts, Al will visually parse the chunk and categorize it into a left nav bar. The user can select a category to view Al’s interpretation and edit if needed.

### Prompt Prompts

It takes time and effort to craft strong prompts. **Prompt Prompts** gives keywords and tags to help generate a good starting point.

### Re-entry Panel

Users often lose track of what they were doing or discussing when returning to an AI chat after some time away, making it hard to regain context and continue. **The Re-entry Panel** provides an always-updated, AI-generated recap of the last session, a list of key topics, and suggested next steps, helping users recall context when opening older chats, letting them seamlessly resume their workflow.

### Side-Panel AI Verification

Users can’t easily trust AI outputs due to hallucinations and lack of context. Manually checking sources is time-consuming. **AI Verification** opens a side-panel showing contradicting information. Users can quickly resolve or ignore issues, updating the output with minimal effort.

### Thematic Chat Grouping

Related chats on the same topic are scattered, making it hard for users to see connections or easily revisit past ideas. **Theamtic Chat Grouping** can cluster chats by shared themes, linking related conversations with summaries and dates so users can easily trace ideas and jump between connected threads.
