# Dashboard Design: 15 Critical Questions Framework

Dashboard design requires understanding three phases: user goals, dashboard architecture, visual design. Before designing ask 15 critical questions identifying specific problem solving, required information, user task requirements understanding design goal-centric. Clear architecture shows actionable, useful information at glance containing vast information using inverted pyramid: most significant top, important details middle, additional bottom. Visual design prioritizes simple design left-to-right movement using colors, shapes, labels supporting structure. Dashboard must answer: what specific problem solving for user? What information achieving goal? What items on to-do list? How easily starting important tasks? How many steps achieving specific goal? Is information clearly and efficiently communicated? Can user find information in 5 seconds? Implements visual hierarchy and data prioritization? What information most actionable for one user type? Does dashboard show trends? Recent activity and problems? Can arranged on single screen monitoring at glance? Using precise, legible descriptive labels? Best data visualization graph or chart? Consistent type and colors? Suggestive easy-understand iconography? Adding too many refinements? Overdoing shadows or textures? Using unnecessary images?

## Key Patterns & Concepts

- **Specific Problem**: Identify particular design solving problem for user
- **Required Information**: What information does user need successfully achieving goal
- **User To-Do**: What items on users' "To Do" list
- **Task Steps**: How easily can user start important tasks; how many steps achieving goal
- **Clear Efficiency**: Is information clearly and efficiently for quick communication
- **5-Second Rule**: Can my user find information in 5 seconds
- **Visual Hierarchy**: Does it implement visual hierarchy and data prioritization
- **Information Actionability**: What information most actionable to one user type vs another
- **Trends and Changes**: Does dashboard show trends and changes in data over time
- **Recent Activity**: Does it show recent activity and problems user should be aware
- **Single Screen**: Can this be arranged on single screen monitoring at glance
- **Precise Labels**: Am I using precise, legible and descriptive labels
- **Right Visualization**: Am I choosing best data visualization graph or chart for information
- **Design Consistency**: Does dashboard use consistent type and colors
- **Iconography**: Is my iconography suggestive and easy to understand
- **Visual Refinement**: Am I adding too many extra refinements, overdoing shadows, textures, unnecessary images
