# One small thing can make a big difference: buttons. And sometimes, you need to show two buttons together — both equally important. This is where the [double button UI](https://www.designmonks.co/blog/show-two-primary-buttons-ui) comes in.

One small thing can make a big difference: buttons. And sometimes, you need to show two buttons together — both equally important. This is where the [double button UI](https://www.designmonks.co/blog/show-two-primary-buttons-ui) comes in.

But here’s the problem — if you place these two buttons wrong, it can confuse your users.

Let’s break it down and learn how to place double button UIs the right way — without making your design messy or hard to use.

## Why Showing Two Buttons Can Be Tricky

Sometimes, you need two buttons side by side — like “Accept” and “Decline” or “Save” and “Don’t Save.”

Both actions are crucial and need to stand out clearly. Yet if they’re positioned too close, too far apart, or without proper visual harmony, the experience breaks down.

That’s why alignment and spacing are key for good design.

## 1. Horizontal Alignment

Best for: Desktop or tablet screens

This is the most common layout for wider screens. You simply place the buttons side by side.

Tips to do it right:

*   Keep a small space (8–16px) between them
*   Make both buttons the same size
*   Put the main action button on the left (for English users)

Example: In a desktop app, show “Submit” and “Cancel” side by side. It feels natural, and users can quickly decide what to do.

## 2. Vertical Alignment

Best for: Mobile screens

Phones are tall, not wide. So, stacking buttons vertically works better here. It saves space and is easier for thumbs.

Quick tips:

*   Keep a 16–24px gap between the buttons
*   Buttons should be big enough to tap (at least 44px tall)
*   Use a strong color for the main action, and a lighter one for the second

Example: On a checkout screen, stack “Pay Now” and “Cancel” buttons. It prevents users from tapping the wrong one by mistake.

## 3. Keep Button Styling Consistent

No matter where you place them, double-button UIs need to look like they belong together.

This means:

*   Same shape and size
*   Same font and style
*   Enough space between them and other elements
*   Button hover and tap effects for feedback

If one button looks different, it may confuse users or make the design look broken.

## 4. When to Use Two Primary Buttons

Use two buttons _only_ when both actions carry equal weight. Don’t overdo it. Don’t force it.

Use it for:

*   Critical decisions like **“Allow”** vs **“Deny”**
*   Choices like **“Save”** vs **“Don’t Save”**
*   Confirming intent with **“Yes”** or **“No”**

Avoid it when: One action is clearly more important, like “Pay Now” vs “Back.”

In those cases, use a primary button and a secondary one. It helps users focus.

## 5. Make It Accessible

Great design is for everyone. For your double button UI to work well, keep accessibility in mind:

*   Use simple labels like “Save” or “Cancel.”
*   Buttons should be easy to tap (48x48px is ideal)
*   Add keyboard support (like using the Tab key)
*   For screen readers, use clear button names like “Confirm Payment”

## Final Thoughts

Designing a double button UI might look simple, but doing it right takes intention. It’s not just about placing two buttons side by side — it’s about guiding the user toward the right decision.

Keep it clean. Make labels clear. Test across devices.

Well-placed buttons can drive action. Poorly placed ones can cause hesitation or drop-offs.

Design with clarity. Keep it intuitive.

Avoid using double buttons when one action is clearly dominant, like “Pay Now” vs “Back.” 

 In such cases, use a primary and a secondary button to direct attention and reduce friction.
