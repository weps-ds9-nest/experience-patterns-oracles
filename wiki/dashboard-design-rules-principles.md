# Dashboard Design: Rules and Principles

Dashboard is at-a-glance preview of crucial information guiding users into decisions, metaphor for car dashboard. Good dashboards clear present required information (5 seconds), meaningful containing understandable story, consistent layout/organization/content, and simple presenting complex information simply. Knowing audience and understanding their background enables valuable design. Audience levels vary; segment dividing information basic vs advanced. Selecting correct KPIs key element designing dashboards. Operational dashboards impart critical information quickly for time-sensitive users engaging proactively efficiently; display deviations clearly, show current resources and status. Analytical dashboards provide at-a-glance information for analysis; less time-sensitive, focused on decision-making helping users understand trends. Dashboard type determined by user roles and needs; multiple roles need unique dashboards. Choosing right data representation complex especially displaying multiple information types; wrong chart choice confuses or misleads. Relationships shown via scatter/network diagrams; comparisons via columns/lines/bars; composition via pie/donut; distribution revealing outliers. Line graphs shouldn't show >5 values, bar charts >7; time always axis X; sort bars by biggest value. Visualization comparing easier than grids; benefit of space efficiency, scalability, ease of development, user comfort with Excel-like grids.

## Key Patterns & Concepts

- **Clear Presentation**: 5-second comprehension of dashboard purpose
- **Meaningful Information**: Story behind visuals understandable to user
- **Consistent Layout**: Format consistency in layout, organization, content
- **Simple Complexity**: Complex information presented simply not simplified incorrectly
- **Know Audience**: Understanding background and comprehension level critical
- **Dashboard Types**: Operational (real-time alerts), Analytical (decision support), Strategic (progress tracking)
- **Audience Segmentation**: Different roles need different dashboards; split information basic/advanced
- **KPI Selection**: Correct metrics critical for success
- **Data Representation**: Match visualization to data story—relationships, comparison, composition, distribution
- **Chart Guidelines**: Line charts max 5 values, bar charts max 7, time as X-axis, sort by value
- **Avoid Poor Charts**: Skip gauges, 3D, overstyled for readability
- **Data Tables**: Great for large datasets; space efficient, scalable, user-familiar
