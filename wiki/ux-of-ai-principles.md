# The UX of AI: Complete Principles Guide

Designing AI products requires eight core principles guiding from user research through system behavior: start with user identifying valuable experience over diving headfirst into algorithms; set right expectations explaining plain language what AI can do and limitations; explain results ensuring users trace back to supporting data points or understand algorithm operation; communicate confidence showing percentage or visualization when algorithm confidence varies; degrade gracefully designing for different outcomes presenting uncertain results differently; know what not to automate avoiding automation of tasks needing human abilities, subjective evaluation, or far-reaching consequences; keep user in control amplifying human abilities via intervention, feedback, reversal, rewards instead of replacing humans; build trust over time with gradual automation as users understand how system works; help users grow allowing AI adapting to changing user behavior; balance predictability and serendipity personalizing while avoiding filter bubbles constraining curiosity; escape personality cult making AI feel home with product avoiding witty personality confusion; avoid chatbots for single tasks as inherently limited; prototype with real data and fake AI using wizard-of-oz; work with diverse teams collaborating across disciplines; extend transparency beyond product telling users data handling, model development choices, interface design rationale.

## Key Patterns & Concepts

- **Start with User**: Guide technology by desired UX; think about task currently; figure out value; find simpler non-AI solutions when applicable
- **Set Expectations**: Explain plainly what AI can/can't do; show limitations; under-promise over-deliver builds trust
- **Explain Results**: Trace results to supporting data; explain algorithm basics; show data sources; break down aggregations
- **Communicate Confidence**: Show percentage or visualization; vary by result parts; offer multiple results by confidence; users decide
- **Degrade Gracefully**: Design for many outcomes; uncertain results presented differently; avoid saying always confident
- **Know What Not to Automate**: Skip automation when: unique human abilities, intrinsic manual value, subjective evaluation, far-reaching consequences
- **Keep User in Control**: Amplify not replace abilities; enable intervention, feedback, reversal, rewards; user remains in control
- **Build Trust Over Time**: Minimal initial data; lean toward suggestions; automate gradually as users understand; algorithms learn together
- **Help Users Grow**: AI adapts to changing user behavior; societal values evolving; avoid being stuck in past learning
- **Balance Predictability and Serendipity**: Personalization for predictable tasks; avoid filter bubbles; enable intuition following off-beaten paths
- **Escape Personality Cult**: AI feels home with product; avoid witty personality confusion; stick to brand values
- **Avoid Chatbots for Single Tasks**: Chatbots inherently limited; dress up as if not; uncertainty frustrates; forms and buttons often better
- **Prototype with Real Data**: Use real user data for early prototypes; wizard-of-oz method; get UX right before building AI
- **Diverse Team Collaboration**: All disciplines involved; data analysts, researchers, developers, marketers, designers; domain experts deeply involved
- **Transparency Beyond Product**: Tell users how data gathered/handled/processed; explain model development choices; consider open-sourcing critical systems
- **Avoid Collecting Unnecessary Data**: Users own data; use on-device ML; collect only if needed; explicit permission and explanation
