# Where Should AI Sit in Your UI: 7 Emerging Layout Patterns

Seven emerging AI UI layouts define mental models users form about AI's role and capabilities. Floating chatbot (bottom-right) secondary asynchronous interface ideal lightweight non-intrusive support; limited real estate prevents proactive reasoning. Inline overlays (Notion, Grammarly) dynamic augmentation tools offering micro-level support directly within content; low-friction immediate interaction. Infinite canvas (Figma, Miro, TLDraw) creative collaborator responding to spatial context supporting parallel LLM calls across objects; suboptimal for strict version control. Centered chat (ChatGPT, Perplexity) general-purpose assistant supporting freeform exploration but not structured multi-step workflows. Side-panel agentic (Canvas, Lovable) strategic partner supporting multi-turn co-creation through chat-output separation; less effective on mobile. Right-panel helper (Copilot, Cursor) deep-context expert providing targeted reasoning support without dominating; subtle presence may go unnoticed. Semantic spreadsheet (AnswerGrid, Elicit) distributed research agent within table; multiple agents work asynchronously; best for research and structured content compilation.

## Key Patterns & Concepts

- **Floating Chatbot**: Secondary interface, bottom-right placement, lightweight non-intrusive, reactive task-bounded; limited for proactive reasoning
- **Inline Overlays**: Dynamic augmentation directly in content, micro-level precision support, low-friction immediate interaction; limited for open-ended exploration
- **Infinite Canvas**: Creative collaborator in spatial context, parallel LLM calls across objects, supports visual thinking; suboptimal for version control
- **Centered Chat**: General-purpose assistant, freeform exploration, prompt-first interaction; limited for structured multi-step workflows
- **Left-Panel Agentic**: Strategic partner, multi-turn co-creation, chat-output separation encouraging iterative refinement; screen space constraints on mobile
- **Right-Panel Helper**: Deep-context expert, targeted reasoning support, on-demand assistance, respects user pacing; subtle presence underutilized by novices
- **Semantic Spreadsheet**: Distributed research agent within table structure, asynchronous autonomous agents, dynamic result population; requires output structure clarity
- **Discoverability**: Varies by layout; floating obvious, inline subtle, canvas contextual, centered minimal, panels peripheral/persistent
- **Interaction Pattern**: Secondary async, dynamic augmentation, parallel spatial, freeform linear, co-creation iterative, on-demand targeted, grid-driven autonomous
- **Perceived Role**: Support reactive, precision assistant, creative collaborator, general assistant, strategic partner, deep expert, research agent
- **Capabilities**: Task-bounded, context-aware, spatial-responsive, broad adaptive, reasoning-driven, specialized expertise, distributed intelligence
- **Limitations**: Real estate, open-ended tasks, version control, mobile, mobile lightweight, discovery, structure clarity
- **Spatial Choices**: More than aesthetic; define mental models, influence behavior, shape trust and interaction patterns
