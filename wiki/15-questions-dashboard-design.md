# Dashboard Design Questionnaire: 15 Questions at Three Phases

Dashboard key feature of web application design providing users quick access to frequently requested data, KPIs, metrics, and analytics. Effective dashboard layout presents data in easily scanned format with most important information immediately visible. Creating efficient dashboard requires prioritizing relevant data, considering usability, guided by business goals. Fifteen questions at three phases guide design: user goals (what problem solved, information needed, user to-do items, task ease and steps), dashboard architecture (information clarity and efficiency, visual hierarchy and data prioritization, actionable information by user type, trends over time, recent activity and problems, single screen arrangement), visual design (precise labels, best data visualization, consistent colors and type, suggestive iconography, minimal refinements).

## Key Patterns & Concepts

- **User Goals Phase**: Identify specific problem dashboard solves, information required, user to-do items, task ease and required steps
- **Problem Solving**: What specific problem design solves for user; goal-centric design solving real problems
- **Information Needs**: Identify information required for user success; key information conveyed clearly
- **Task Efficiency**: How easily users start important tasks; steps needed complete specific goal
- **Dashboard Architecture**: Clear and intuitive display; actionable and useful information at glance containing vast amounts
- **Visual Hierarchy**: Information clearly/efficiently for quick communication; user finds information 5 seconds; implements visual hierarchy and data prioritization
- **Actionable Information**: Different information for different user types; shows trends/changes over time; shows recent activity and problems; single-screen arrangement for at-glance monitoring
- **Visual Design Phase**: Simple design moving left to right; colors, shapes, labels supporting structure
- **Label Precision**: Precise, legible, descriptive labels essential
- **Data Visualization**: Choose best graph/chart for information; consistent type and colors; suggestive/easy-to-understand iconography; minimal extra refinements
- **Design Balance**: Avoid extra refinements, overdoing shadows/textures, unnecessary images
