# 30 User Research Questions for Dashboard Design

Deciding relevant information display in dashboard tricky; users give every metric produced. Sufficient asking what users want; must understand why data needed and how used. Without proper user research, dashboard risks creating fancy-looking charts not informative or actionable. Thirty user research questions uncover four areas: user's goals, context of use, timeliness and interactivity requirements, familiarity with data metrics and terminologies. Use questions during contextual inquiries, interviews, or surveys. Three main dashboard purposes: setting goals and tracking progress (strategic), monitoring real-time performance (operational), identifying opportunities or investigating problems (analytical). Users often have multiple purposes.

## Key Patterns & Concepts

- **User Goals Understanding**: What top goals and priorities; how numbers help; most important tasks; why important; success definition; how measure success; progress evaluation
- **Strategic Dashboard Goals**: What success looks; how measure success; progress evaluation scenario
- **Operational Dashboard Goals**: What decisions frequently needed; questions regularly asked; walk through normal work day
- **Analytical Dashboard Goals**: How identify improvement opportunities; last data understanding moment; mistakes/opportunities preventable with data
- **Context of Use**: When would dashboard used (quick glance vs deep analysis); triggers prompting data review; review context; review frequency; time usually spent
- **Outcomes Decision Making**: What would do with certain data; how use numbers deciding; thresholds prompting action; increase/drop/plateau response
- **Timeliness Requirements**: What information needed daily; how often review specific data; information needed trends vs single point; importance reasons
- **Interactivity Requirements**: What numbers compare to (historical, average, company, location); next steps after seeing data; how share information
- **Data Proficiency**: Last data work experience, tool used, questions answered, making sense approach; Excel usage; report/analytics tools enjoyed; preferences (in-depth vs quick glance)
- **Metrics Familiarity**: Currently tracked metrics; why important; how decide which metrics; aware of peer metrics
- **Terminologies Understanding**: Challenges faced first using analytics; take note of user language patterns
- **Expertise Spectrum**: Users fall anywhere from complete data illiteracy to statistics expertise; need understanding how sophisticated users with data
- **Exploration Inclination**: Do users enjoy digging into data; how much explanation/support needed
- **Expert Terminology**: Ensure industry/analytics terminologies well-understood; first-time users may not understand analytics concepts
