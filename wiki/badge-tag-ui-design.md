# Badge and Tag UI Design

Badges (also called tags) are small visual elements providing additional information or visual cues highlighting statuses, categories, notifications. Effective badge design focuses on usability and visual appeal through understanding anatomy (text/icon, background, border, pill shape), leveraging different states (default, active, inactive, success, error, warning), styling to match branding/themes, and applying across notifications, labels, statuses, categories, indicators. Usability considerations include legibility, contrast, accessibility, positioning, and interaction clarity.

## Key Patterns & Concepts

- **Badge Anatomy**: Text/icon content, background color/fill, border/outline, pill-shaped container
- **States**: Default (neutral), active (selected/focused), inactive (disabled), success (positive), error (critical), warning (alert)
- **Styling Customization**: Colors matching branding, fonts for consistency, sizes for context, border styles for definition
- **Use Cases**: Notifications (unread items, alerts), labels (categorization, filtering), statuses (online/offline, processing, complete), categories (topic tags), indicators (count badges, new items)
- **Legibility**: Sufficient contrast between text and background; readable at small sizes; clear typography
- **Accessibility**: ARIA labels for screen readers; semantic HTML; keyboard interaction support
- **Positioning**: Contextual placement (top-right for notifications); consistent positioning across application
- **Interaction**: Hover states for interactive badges; click/tap regions clear; visual feedback for selection
- **Visual Hierarchy**: Size and color convey importance; multiple badges organized without clutter
- **Color Semantics**: Consistent color meaning (green=success, red=error, yellow=warning) across system
